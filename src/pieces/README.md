# Chess piece artwork

The twelve individual chess piece SVGs in this directory are by
[Cburnett](https://commons.wikimedia.org/wiki/User:Cburnett) and the contributors
listed in each Wikimedia Commons file history. ChessMerge uses these images under
[Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/).
The [full license](https://creativecommons.org/licenses/by-sa/3.0/legalcode) applies
to this artwork separately from the application's Apache 2.0 license.

The SVG content matches the Wikimedia Commons originals. Only XML formatting and
line endings differ.

ChessMerge scales and crops the pieces and pairs them to show merged pieces. These
artwork adaptations are also available under CC BY-SA 3.0. The source pages below
identify the original works and their revision histories.
